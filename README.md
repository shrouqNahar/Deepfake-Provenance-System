# Provenance-Aware Hybrid Deepfake Detection Framework

A reproducible multimedia forensic framework for deepfake image detection that integrates CNN-based semantic analysis with lightweight provenance verification and explainable AI.
The framework combines EfficientNet-B0 and ResNet50-based deepfake detection with perceptual hash (pHash) provenance verification through a confidence-aware hybrid fusion mechanism. It is designed to evaluate forensic robustness under dissemination-related transformations such as resizing, JPEG compression, Gaussian blurring, and incomplete metadata conditions commonly encountered in Social IoT-oriented multimedia environments.

# Key Features
•	CNN-based deepfake detection using EfficientNet-B0 and ResNet50
•	Lightweight provenance verification using perceptual hashing (pHash)
•	Confidence-aware hybrid fusion between detector confidence and provenance consistency
•	Grad-CAM explainability for forensic transparency
•	Provenance survivability analysis under multimedia transformations
•	Ablation analysis and computational overhead evaluation
•	Reproducible experimental pipeline with evaluation scripts and trained models

# Experimental Analyses
•	ROC and Precision–Recall analysis
•	Confusion matrix evaluation
•	Provenance survivability experiments
•	Hybrid fusion ablation study
•	Computational complexity assessment
